fleet & work

Every machine at once, and the apps you work in

Agents run on many machines. ag gathers what they say, show and ask into one place without a central server, and a set of work tools lets them search the web and read the apps where work actually happens.

Nodes come from ~/.config/ag/config.yaml (or $AG_CONFIG); --host narrows to some, --local skips SSH entirely. Every command has a --json envelope, and ag mcp exposes 19 typed tools to agents. Read-only tools need nothing more; tools that change state, such as muting speech, answering questions or creating a config, require confirmed=true.

Web search

search_web answers a question from live web results, with citations, through GitHub Copilot's Responses API, using Pi's own automatically refreshed Copilot token. It can also go through an OpenAI-compatible proxy. A /web-search prompt template wraps it, and a separate MCP server offers the same to other agents.

Work apps

Many work apps have no usable API for an agent. App automation gives agents a catalogue of approved, high-level actions instead of raw browser scripting: open, snapshot and summarise Slack, Outlook mail and calendar, Teams and calendars, each with a deterministic plan that can be dry-run first.

  1. Check the setup

    app_automation_doctor checks the catalogue, browser tooling and bridges.

  2. See what is stale

    app_automation_refresh_staleness reports per-action freshness.

  3. Refresh

    Through Playwright, Tendril, or a Windows devbox's browser over the Chrome DevTools protocol when that is where you are signed in. Snapshots are bounded and redacted; cookies and tokens are never stored.

  4. Ask

    app_automation_work_briefing builds a compact, staleness-aware index across all of them for questions such as "what needs me today?".

Slack also has native slack_* tools that return compact results, with messages grouped by conversation and user names resolved once, and writes that require explicit confirmation.

Skill and tool discovery

skill-search lets an agent find configured skills and host MCP servers without reloading anything, as one CLI and one MCP meta-tool:

skill-search list --jsonskill-search web query latest Rust MCP crateskill-search mcp stdio

linear-extra wraps a Linear MCP server with draft support.
