# agent-utils docs

Long-form guides for individual extensions and tools (speech, choices, previews, sessions,
fleet tools and more). They are repository documentation, read on GitHub.

The public site at https://a.skh.am/agent-utils/ is built from [`../site/`](../site/), not from
this directory: edit pages there, then run `npm run docs:build` and `npm run docs:check`.
Keep the site public-safe: no secrets, private snapshot contents, host names or local state.
