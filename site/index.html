overview

The toolbox around a coding agent.

Agent Utils is a Pi package and a handful of standalone tools that give a coding agent a voice, eyes, hands and a fleet. Speech goes in and out; images and screens get shared both ways; questions reach whichever device you are holding; sessions compact, resume, fork and update themselves; and one command shows every machine at once.

  • 42Pi extensions
  • 5standalone tools: ag, pi-session, skill-search, web-search-mcp, linear-extra-mcp
  • 1install: pi install git:github.com/harryaskham/agent-utils@v1

How it is built

Opt in, fail safe
Speech, auto-updates, agent queue tools and display helpers are off until asked for, and guarded when on: a missing provider or display is a clear message, never a hang.
Local first, fleet aware
Everything works in one Pi session on one machine. Durable archives on each machine then let ag give a fleet-wide view without a central server.
Independent of the host
Every extension works on its own. When the Paratenic session host is present, the same features are also offered to its remote clients through the Agent Host Protocol, using one state machine for local and remote input.
Agents and operators are different users
Operator commands are unrestricted; agent-callable tools such as model self-selection, speech mute and question answering are narrower or need confirmation.
