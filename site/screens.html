Images, terminals and desktops

Agents make and inspect a lot of pictures: screenshots, renders, diagrams, emulator frames. Agent Utils shows them inline in the terminal, keeps them in durable archives, puts them into the model's context only when asked, and gives agents displays, emulators and VMs of their own to look at.

A gallery in the terminal

The kitty image preview is a persistent widget in the Pi session that draws images with the kitty graphics protocol: above or below the editor, or in a side panel sized to the image. Agents add images, folders or live screenshot streams; you page through them with /image-next, /image-prev and /image-hide.

_show, _animate, _cycle, _statusNavigate, animate a series, cycle on a timer, inspect

It works through tmux, SSH and terminal multiplexers. Under tmux it uses Unicode placeholders, so images stay anchored to their cells and scroll with the pane. Each image's bytes are uploaded once, and redraws only re-place it. Cleanup deletes only the image ids it created, never every image on the terminal. Any still image can be described by a vision model with describe: true, as text metadata.

Local by defaultPreviews, galleries and streams stay on your screen. An image enters the model's context, and the session's durable history, only through an explicit share. That keeps context small and private screens private.

Shared images and recovery

  • Every image an agent shares is copied into a durable per-machine archive under ~/.local/state/agent-utils, with a private sidecar recording its provenance and checksum, independent of any session. ag image gathers these archives across machines into one gallery (see Fleet).
  • If a provider rejects the latest image with HTTP 413, the image is too large. Agent Utils makes an exact half-width, half-height copy, replaces just that attachment in future context with a note giving the path, and retries once.

Editor chrome

/gfx drives Pi's graphics effects and themes. Editor chips move the model, effort, MCP, cost, context, directory, branch and diff into Powerline-style chips around the editor, collapsing gracefully on narrow terminals. /eink switches a tablet or e-ink screen to a greyscale theme with static chrome and no animation, and /eink off puts everything back.
